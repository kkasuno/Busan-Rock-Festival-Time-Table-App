- 기존 10개 위치를 유지하고, 캡처에서 이름이 확인되는 35개 위치를 추가: 총 45개 핀.

- 원본은 사용자 제공 `KakaoTalk_20260929_134554614*.jpg` 12장. 캡처 파일 자체는 업로드 폴더에 포함하지 않는다.
- 좌표는 2026 일러스트의 백분율. 북쪽 위 카카오 캡처와 남쪽 위 안내도를 구역별로 대조한 **근사 위치**이며, 카카오 장소 좌표를 추출하거나 GPS 실측한 것이 아니다.
- 기존 안내도 배치 크기·176도 회전·시계탑 기준점 및 5개 무대 위치는 변경하지 않았다.
- 중앙 구역은 시계탑 마름모, 사각 순환로, 경기장/히든 구역의 방향 관계를 기준으로 배치. 로컬푸드와 리버는 그림이 실제 지도와 달라 별도로 부스 순서와 도로 가장자리를 맞췄다. 길찾기나 안전상 정밀한 위치 근거로 사용하지 않는다.

## 검증

- `npm run build:upload`: 성공. 새 이미지나 지도 SDK 의존성 추가 없음. 메인 JS 약 10.7 kB 증가(압축 전, 음식점 버전 대비).
- 음식점/위치/지도변환/제스처/오프라인/결산 테스트 46개 통과.
- TypeScript 검사: 변경한 지도 모듈 오류 없음. 기존 서버 전용 Cloudflare 타입 3개 오류(`cloudflare:workers`, `Fetcher`, `D1Database`)는 남아 있음.
- 카카오 실연결: `http://localhost:4180/`에서 타일·중첩 안내도·부스 필터·상세 이동·방향 전환 및 겹친 장소 선택 확인.
- 320px 화면에서 가로 넘침 없음. 390px 안내도에서 겹친 핀 → 수안커피 메뉴 연결 확인. 1280px 카카오 화면에서 중앙광장 핀과 상세 확인.
- 클러스터를 열자마자 목록을 누를 때 400ms 제스처 클릭 차단에 걸리는 문제 수정 및 회귀 테스트 추가. 실제 카카오 화면에서 빠른 연속 클릭으로 CGV 상세 열림 확인.
- 기존 localhost 기록의 뱃지 4/17은 업데이트 후 동일. 기록을 수정하거나 초기화하지 않음.
- 최종 390px 카카오 화면에서 음식점 3개 핀, 겹친 CGV/이흥용과자점/삼진어묵 선택 목록, 장호밀면의 위치 미확인 상태 확인. 콘솔 오류 없음. 캡처: `artifacts/venue-booths-mobile.png`.
- ZIP 검사: 루트 index.html 포함, 42개 파일, 음식 사진 25장, 진단/편집기/원본 캡처 파일 없음. ZIP 4,493,809바이트. 이전 음식점 미리보기 ZIP은 그대로 보존.
